Start python tools/dev_server.py from the portfolio folder (not plain http.server). Open the editor URL printed in the terminal (default port 8765), then click Save to write data/data.json. Upload screenshots on each project — they go to assets/images/ automatically. Commit and push both JSON and new images for GitHub Pages. Edits auto-save as a browser draft until you save to disk.
